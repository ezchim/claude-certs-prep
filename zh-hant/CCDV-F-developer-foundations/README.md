## 考試機制（官方考試指南 1.0 版，2026 年 7 月）

數值來自官方考試指南 1.0 版（2026 年 7 月），並對照公開的 Pearson VUE Anthropic 計畫頁面交叉查核：

| 項目 | 官方數值 |
| --- | --- |
| 考試代碼 | **CCDV-F** |
| 題數 | **53** 題 |
| 時間 | **120** 分鐘 |
| 及格分數 | 量尺分數 **100–1000** 中的 **720** |
| 題型 | 單選題＋複選題；每題會註明要選幾個選項（「約 1/4 為複選題」這個比例屬傳聞，並非來自考試指南） |
| 交付 | Pearson VUE（考場或線上監考），英文 |
| 費用 | 每次 **USD $125** |
| 有效期 | **12 個月**，有免費的準時續約評量；重考等待 14／30／90 天，每滾動 12 個月最多 4 次 |
| 建議經驗 | 1–5 年工程資歷＋約 6 個月以上 Claude／LLM 實作；Python 及／或 TypeScript |

粗略配速：每題約 2.3 分鐘。情境題的題幹很長——先讀**限制**（延遲、成本、安全、快取穩定性），再看選項。

## 官方八大考試領域（配分比重來自考試指南 1.0 版）

| 領域 | 配分比重 | 學習強度 |
| --- | --- | --- |
| 應用與整合 | **33.1%** | 最高 — API、串流、快取、批次對即時、schema、設定／版本釘定 |
| 模型選擇與最佳化 | **16.8%** | 高 — 模型家族、effort、成本／延遲、上下文視窗 |
| Agent 與工作流程 | **14.7%** | 高 — agent 迴圈、Agent SDK 模式、編排 |
| 提示與上下文工程 | **11.0%** | 中高 — 系統提示詞、上下文預算、壓縮 |
| 工具與 MCP | **10.6%** | 中高 — 工具設計、MCP 伺服器／用戶端、connector |
| 安全與防護 | **8.1%** | 中 — 機密、個人識別資訊（PII）、護欄、破壞性動作關卡 |

## 建議學習順序（主要路徑）

1. **先瀏覽本 README**＋領域配分比重（30 分鐘）。

3. **第 01 章（模型選擇與最佳化，簡稱 MSO）** — 鎖定模型／effort／成本決策樹（16.8%＋整合題裡的成本／延遲題幹）。
4. **第 02 章（提示／Agent／工具）** — Agent 14.7%＋提示 11%＋工具／MCP 概念那一半的 10.6%＋API 工具合約。
5. **第 04 章（生產工程／評測／安全）** — 安全 8.1%＋評測 2.6%＋生產整合模式。
6. **第 05 章（加速器）** — 打包與交接（以情境題形式支撐整合＋Agent＋評測）。
7. **第六章（框架／託管／SDLC）** — Strands／LangGraph／PydanticAI 詞彙、自託管對託管 agent、SE／SDLC 卡片、WebSocket 對 SSE（收尾最優先缺口）。

**離線閱讀提示：** 每個檔都是純 Markdown（ATX 標題、表格、圍欄 `text` 樹狀圖）。若喜歡電子閱讀器格式，可用你慣用的 MD→EPUB 工具轉換；維持一章一檔。
