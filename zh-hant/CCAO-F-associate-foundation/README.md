## 考試機制（取自已發布指南）

| 項目 | 細節 |
| --- | --- |
| 題數 | **60**（全部計分） |
| 時間 | **120** 分鐘（平均約 2 分鐘／題） |
| 題型 | 單選題＋複選題；每題註明要選幾個選項（「約 1/4 為複選題」僅為軼聞，並非出自指南） |
| 及格分數 | 量尺分數 **100–1000** 中的 **720** |
| 語言 | 英文 |
| 交付 | Pearson VUE — 線上監考或考場 |
| 費用 | 每次約 USD $99（報名時確認） |
| 有效期 | **12** 個月；免費準時續約評測；失效後須重考完整考試 |
| 重考 | 常被引用的等待期：14／30／90 天；滾動一年內有次數上限 |
| 成績報告 | 及格／不及格＋量尺分數；各領域答對百分比僅供參考 |

**訣竅：** 按 **配分比重**（見下）研讀各領域檔，不要按檔案編號。檔案編號依循使用者的 7 領域地圖；官方藍圖編號略有不同，但涵蓋同一組七個主題。

## 建議研讀順序（按考試配分比重）

1. **領域 03 — 評估與驗證輸出（21%）** — 從這裡開始；判斷類題目主導整張考卷。 
2. **領域 04 — 工作流程整合與解決方案設計（16%）** — 情境題、利害關係人、重新設計。 
3. **領域 06 — 治理、風險與負責任使用（15%）** — 政策、隱私、高風險使用。 
4. **領域 02 — 提示與任務執行（14%）** — 打磨、拆解、迭代。 
5. **領域 01 — 平台與模型基礎（12%）** — 功能＋ Haiku／Sonnet／Opus（／Fable）。 
6. **領域 05 — 設定與知識管理（12%）** — Projects、指示、connectors。 
7. **領域 07 — 疑難排解與最佳化（10%）** — 診斷薄弱輸出／工作流程。

**實作（公開產品）：** 在 claude.ai／Claude Desktop 上練習 Projects、Artifacts、Skills、Connectors、Research（Research／檢索增強生成（RAG）容量需付費方案）。研讀時搭配公開 Academy：Claude 101＋ AI 流暢度（4D：委派（Delegation）、描述（Description）、明辨（Discernment）、盡責（Diligence））。

## 學習包維護（更新於 2026-08-23）

- **全部七個領域檔現為去重後的單一主要研讀本。** 先前的灌水模式（同一組演練區塊在每檔貼上 7–15 次）已從檔案 01、02、04、05、06、07 移除，與乾淨的領域 03 重寫對齊。每檔現在都有深入筆記、決策樹、考試陷阱，以及 15–25 題真實情境問答與理由。
- **覆蓋缺口已補上：** claude.ai **Memory**（出現在官方考試指南的準備清單與領域 3 目標）主要講述見 `05-…`，並在 `01-…` 有選擇面小節；**程式碼執行與檔案產生**（指南亦點名）在 `01-…`（功能）與 `04-…`／`07-…`（工作流程與疑難排解用途）講述。
- **已新增 `PRO-TIPS.md`（2026-08-23）：** 應試技巧伴讀 — 四大核心直覺、反射表、干擾選項原型、48 小時計畫。讀完領域檔之後再讀它。
- **方案事實已對照 support.claude.com 重新查證（2026 年 8 月）：** Free＝最多五個 Projects、一個自訂 connector；Project RAG＝付費方案，知識容量最多擴大約 10 倍；Memory 產生在 Free／Pro／Max（Enterprise 為舊版體驗），對話搜尋在 Pro 以上；無痕對話所有方案都有。方案上限會變 — 考試前重新查證。
