# CCAO-F 應試技巧 — 如何把這場考試考好

*伴讀領域檔 01–07；於 2026-08-23 從官方考試指南 1.0 版與本學習包提煉。只談應試技巧 — 內容在各領域檔裡。*

**這場考試真正獎勵的是：** *身為專業使用者的判斷力*，不是技術知識。配分最重的領域是輸出評測（21%），而大多數題目底下反覆出現的問題是：**「在信任或交付 Claude 的輸出之前，這個人該做什麼？」** 有疑問時，選那個增加驗證步驟、人工關卡或設定修正的答案，勝過那個換更大模型或加長提示詞的答案。

---

## 驅動策略的數字

- **60 題／120 分鐘 → 每題 2 分鐘。** 這些題幹比開發者考試短 — 風險不是時間，而是想太多。第一個站得住腳的判讀會贏；把真正一半一半的題目標記起來，然後往前走。
- **量尺分數 720，猜題不扣分** — 每一題都要答。
- **按配分比重分流：** 評測 21%＋工作流程設計 16%＋治理 15%
＝ 52%。這些全是判斷力領域 — 它們共享同一個直覺（驗證、把關、承擔），所以練好一個，三個都會變強。
- **複選題是全對才給分**；每題會註明要選幾個選項。

## 四大核心直覺（大多數題目可化約成其中之一）

1. **東西出門之前先驗證。** 有引用來源 → 打開它。有數字 →
 重算或抽查。合規／對外發送 → 先經人工檢視。
 （指南自己的範例題：合規發送之前，先驗證引用來源。）
2. **模型要選對大小。** 大量、簡單、重複 → 較輕／較便宜的
 層級。深度分析、高風險 → 較強層級。「永遠用最大的」
 永遠是錯的（學習包甚至把 Fable 最大化主義埋成陷阱）。
3. **先修設定，再怪模型。** 共享 Project 裡的輸出很弱 → 先檢查指示、過期知識檔、缺少負責人、放錯位置 — *然後* 才考慮更動模型／提示詞（見〈疑難排解與最佳化〉的完整邏輯）。
4. **保護資料。** 受監管／個人識別資訊（PII）內容 → 上傳前先匿名化，一次性敏感查詢用無痕對話，尊重方案層級控制。（範例題：受監管的 PII 先匿名化。）

## 題幹說 X → 想 Y

| 題幹訊號 | 反射動作 |
| --- | --- |
| 「該不該發送／發布／提交？」 | 還不要 — 先說出驗證步驟 |
| Claude 引用了來源／給了統計數字 | 查證來源存在且真的那樣說；引用來源可能是錯的 |
| 同一個簡單任務要跑幾百次 | 較輕模型＋可重複使用的提示詞／Project，不要預設 Opus |
| 團隊從共享 Project 一直拿到不一致的輸出 | 知識衛生：重複／過期檔案、沒有負責人、沒有版本註記（見檔案 05 的品牌語氣神祕漂移案例） |
| 這份知識該放在哪裡？ | 把 **存放位置**（指示 vs 知識 vs Skill vs connector vs Memory）搭配 **生命週期**（負責人、節奏、封存） |
| 「Claude 記錯了」／個人脈絡問題 | 編輯／刪除該筆 Memory 條目；Memory 以個人為單位 — 它永遠無法讓團隊對齊（專案知識可以） |
| 事情敏感、不該留存 | 無痕對話（排除在歷史紀錄／記憶／搜尋之外） |
| 資料分析、檔案輸出、圖表 | 程式碼執行／檔案產生 — 不是「叫 Claude 憑空想像一份試算表」 |
| 一直在變動的即時文件 | 用 Connector，不要每週重新上傳；穩定政策文件 → 上傳即可 |
| 「高風險用途」（法律、醫療、雇用決策） | 人的課責性不變；Claude 起草／支援，由人做決定 |

## 預期會出現的干擾選項原型

- **信任型答案：** 因為「看起來對」或「Claude 通常很準」就交付。在配分 21% 的評測領域裡，這永遠不是答案。
- **更大模型型答案**，用來應付其實是工作流程／設定的問題。
- **權限過度分享：** 「給所有人編輯權限，這樣就不會有人被擋住」／
 把受限制知識全組織分享。最小權限原則在這裡一樣勝出。
- **記憶混淆：** 在需要共享專案知識的地方用個人 Memory，或反過來。
- **方案事實唬人題：** 選項建立在捏造的方案上限上。你真正知道的錨點：Free＝5 個 Projects，分享＝Team／Enterprise，付費檢索增強生成（RAG）會擴大知識容量 — 比這些更冷門的說法，用原則判斷。

## 時效觀察清單（考試那一週重新查證）

方案上限與功能可用性在這裡變動最快：Projects 上限、Memory
可用性／控制、Research／connector 的方案門檻 — 花 10 分鐘到
support.claude.com。本學習包已查證的事實日期為 2026 年 8 月。

## 48 小時計畫

1. 完整重讀檔案 03（21%，而且它訓練核心直覺），然後檔案
 04 與 06。
2. 重做每一檔的陷阱表＋複選題模式庫。
3. 到了這個階段，實戰練習勝過重讀：評測三個真實 Claude 輸出，
 各寫一則交付／修改／退件註記；建立一個含指示
 ＋知識＋分享決定的 Project。
4. 計時 60 題模擬考；只複習你答錯的部分。

## 考試當日（線上監考）

身分證件、清空桌面、環境掃描、穩定連線。兩分鐘節奏：讀
題目那句話，找出誰有風險／什麼東西即將出門，
選驗證／把關／承擔的答案。複查時，只在看錯事實時才改答案 — 你校準過的直覺，是這些演練的產物。
