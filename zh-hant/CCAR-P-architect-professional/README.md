## 考試機制（官方考試指南 v1.0，2026 年 7 月）

| 項目 | 值 |
| --- | --- |
| 題數 | **63** 題 |
| 時間 | **120** 分鐘（平均約 1.9 分鐘／題） |
| 及格分數 | 量尺分數 **720**（範圍 **100–1,000**） |
| 題型 | 單選題＋複選題（「選兩項／三項」）；多為長篇、多重限制的情境題 |
| 交付 | Pearson VUE（線上監考或考場） |
| 有效期 | **12** 個月；準時續約免費、免監考 |
| 費用 | 每次應考 **USD $175** |
| 重考 | 等待期 14／30／90 天；任何滾動 12 個月期間最多 4 次 |
| 前置條件 | 無強制要求；**強烈建議具備生產環境 Claude 架構經驗**；CCAR-F 有幫助但非必須 |

**計分說明：** 量尺計分的意思是 720 **不是**固定的答對百分比。複選題通常需**全部**選對才給分——不要假設有部分給分。

## 建議研讀路徑（4–6 週）—— 主要來源模式

1. **第 1 週：** 檔 01 —— 模型、提示工程、上下文、架構模式；做完第 J 部分情境題。 
2. **第 2 週：** 檔 02 整合那一半 —— RAG、MCP、授權（authZ）、延遲、能力膨脹（配分最重）。 
3. **第 3 週：** 檔 02 評測那一半＋檔 03 安全／治理；跑失效模式表。 
4. **第 4 週：** 檔 04 利害關係人／生命週期／變革／價值（標出僅限夥伴的 GTM 界線）＋檔 05 賦能；混合情境題。 
5. **第 5–6 週：** 計時 63 題／120 分鐘套題；弱點迴圈；從情境題庫冷寫架構決策紀錄（ADR）。

動手練習：一條 RAG 路徑、一條工具／MCP 路徑、一個評測框架、一個 HITL 閘門、一次 Claude Code 組織設定模擬執行（即使只當成文件審查）。

**主要學習訣竅：** 對每一個官方領域，你都要能大聲講解：(1) 決策樹，(2) 一張取捨對照表，(3) 最重要的三種失效模式，(4) 會擋住正式發佈（GA）的生產檢查清單項目。
