# 跨認證協同學習包 — 學一次，用四次

*為連續應考而設計 — 同一週內應考四張認證中的兩張以上時最有用。*

## 這個學習包是什麼

四張考試以**四種不同高度測驗同樣的十條心法**，外加一小組真正共享的事實。本學習包把這些集中起來，讓你只學一次，再精確標出各考試**分歧**之處，使共享知識絕不滲進錯誤的答題卷。

| 檔案 | 用途 |
| --- | --- |
| `01-shared-core.md` | 十條心法＋共享事實，每條附一張四考試對照框架表 — 約佔總內容的三分之一，只應學一次 |
| `02-divergence-map.md` | 防污染：範圍圍籬、術語差異、各考試獨有內容，以及「同一題幹、不同正確答案」的案例 |

## 這個學習包不是什麼

- **不是**四份個別學習包的**替代品** — 每張考試都有大量獨有內容（CCAO 的產品判斷、CCAR-F 的 Agent SDK 機制、CCDV 的整合細節、CCAR-P 的軟性領域約 35%），只有該考試自己的學習包才涵蓋。
- **不是合併內容。** 考試在範圍或詞彙上不一致時，以分歧地圖為準 — 每張考試當天早上讀它。

## 誠實的重疊全貌

- **心法重疊：高**（`01` 裡的十條原則在每本指南的範例題與考試目標中反覆出現 — 協同效應就在這裡）。
- **CCDV ↔ CCAR-P 事實重疊：高**（快取、批次、模式、模型選擇 — 多半是相同技術事實，建造者高度對架構師高度）。
- **CCAR-F ↔ CCDV 事實重疊：中等，帶圍籬**（agent／工具／Claude Code 在概念上共享，但 CCAR-F 排除數個 CCDV 核心主題）。
- **CCAO ↔ 三張技術考試事實重疊：低**（模型層級與驗證直覺可遷移；幾乎沒有別的能遷移 — 不要為 CCAO 讀 API 機制，也不要為 CCDV 讀 Projects 機制）。

## 怎麼使用

1. 第 1 天：從頭到尾讀完 `01-shared-core.md` — 它是所有東西掛上去的脊柱。
2. 然後：按考試順序，每張考試做一次專注複習，並在該週後段做第二輪。
3. 每個考試日早上：花 20 分鐘讀 `02-divergence-map.md` 裡屬於該考試的欄 — 只讀圍籬與詞彙，別的都不讀。
