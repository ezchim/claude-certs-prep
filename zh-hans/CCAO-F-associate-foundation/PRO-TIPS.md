# CCAO-F 应试技巧 — 如何把这场考试考好

*伴读领域文件 01–07；于 2026-08-23 从官方考试指南 1.0 版与本学习包提炼。只谈应试技巧 — 内容在各领域文件里。*

**这场考试真正奖励的是：** *身为专业用户的判断力*，不是技术知识。配分最重的领域是输出评测（21%），而大多数题目底下反复出现的问题是：**「在信任或交付 Claude 的输出之前，这个人该做什么？」** 有疑问时，选那个增加验证步骤、人工关卡或设置修正的答案，胜过那个换更大模型或加长提示词的答案。

---

## 驱动策略的数字

- **60 题／120 分钟 → 每题 2 分钟。** 这些题干比开发者考试短 — 风险不是时间，而是想太多。第一个站得住脚的判读会赢；把真正一半一半的题目标记起来，然后往前走。
- **量表分数 720，猜题不扣分** — 每一题都要答。
- **按配分比重分流：** 评测 21%＋工作流程设计 16%＋治理 15%
＝ 52%。这些全是判断力领域 — 它们共享同一个直觉（验证、把关、承担），所以练好一个，三个都会变强。
- **多选题是全对才给分**；每题会注明要选几个选项。

## 四大核心直觉（大多数题目可化约成其中之一）

1. **东西出门之前先验证。** 有引用来源 → 打开它。有数字 →
 重算或抽查。合规／对外发送 → 先经人工查看。
 （指南自己的样例题：合规发送之前，先验证引用来源。）
2. **模型要选对大小。** 大量、简单、重复 → 较轻／较便宜的
 层级。深度分析、高风险 → 较强层级。「永远用最大的」
 永远是错的（学习包甚至把 Fable 最大化主义埋成陷阱）。
3. **先修设置，再怪模型。** 共享 Project 里的输出很弱 → 先检查指示、过期知识文件、缺少负责人、放错位置 — *然后* 才考虑更动模型／提示词（见〈故障排除与优化〉的完整逻辑）。
4. **保护数据。** 受监管／个人识别信息（PII）内容 → 上传前先匿名化，一次性敏感查询用无痕对话，尊重方案层级控制。（样例题：受监管的 PII 先匿名化。）

## 题干说 X → 想 Y

| 题干信号 | 反射动作 |
| --- | --- |
| 「该不该发送／发布／提交？」 | 还不要 — 先说出验证步骤 |
| Claude 引用了来源／给了统计数字 | 查证来源存在且真的那样说；引用来源可能是错的 |
| 同一个简单任务要跑几百次 | 较轻模型＋可重复使用的提示词／Project，不要默认 Opus |
| 团队从共享 Project 一直拿到不一致的输出 | 知识卫生：重复／过期文件、没有负责人、没有版本注记（见文件 05 的品牌语气神秘漂移案例） |
| 这份知识该放在哪里？ | 把 **存放位置**（指示 vs 知识 vs Skill vs connector vs Memory）搭配 **生命周期**（负责人、节奏、封存） |
| 「Claude 记错了」／个人上下文问题 | 编辑／删除该条 Memory 条目；Memory 以个人为单位 — 它永远无法让团队对齐（项目知识可以） |
| 事情敏感、不该留存 | 无痕对话（排除在历史记录／记忆／搜索之外） |
| 数据分析、文件输出、图表 | 代码执行／文件产生 — 不是「叫 Claude 凭空想象一份电子表格」 |
| 一直在变动的即时文档 | 用 Connector，不要每周重新上传；稳定政策文档 → 上传即可 |
| 「高风险用途」（法律、医疗、雇用决策） | 人的问责性不变；Claude 起草／支持，由人做决定 |

## 预期会出现的干扰选项原型

- **信任型答案：** 因为「看起来对」或「Claude 通常很准」就交付。在配分 21% 的评测领域里，这永远不是答案。
- **更大模型型答案**，用来应付其实是工作流程／设置的问题。
- **权限过度分享：** 「给所有人编辑权限，这样就不会有人被挡住」／
 把受限制知识全组织分享。最小权限原则在这里一样胜出。
- **记忆混淆：** 在需要共享项目知识的地方用个人 Memory，或反过来。
- **方案事实唬人题：** 选项创建在捏造的方案上限上。你真正知道的锚点：Free＝5 个 Projects，分享＝Team／Enterprise，付费检索增强生成（RAG）会扩大知识容量 — 比这些更冷门的说法，用原则判断。

## 时效观察清单（考试那一周重新查证）

方案上限与功能可用性在这里变动最快：Projects 上限、Memory
可用性／控制、Research／connector 的方案门槛 — 花 10 分钟到
support.claude.com。本学习包已查证的事实日期为 2026 年 8 月。

## 48 小时计划

1. 完整重读文件 03（21%，而且它训练核心直觉），然后文件
 04 与 06。
2. 重做每一份文件的陷阱表＋多选题模式库。
3. 到了这个阶段，实战练习胜过重读：评测三个真实 Claude 输出，
 各写一则交付／修改／退件注记；创建一个含指示
 ＋知识＋分享决定的 Project。
4. 计时 60 题仿真考；只复习你答错的部分。

## 考试当日（在线监考）

身份证件、清空桌面、环境扫描、稳定连接。两分钟节奏：读
题目那句话，找出谁有风险／什么东西即将出门，
选验证／把关／承担的答案。复查时，只在看错事实时才改答案 — 你校准过的直觉，是这些演练的产物。
