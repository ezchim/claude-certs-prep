**读者：** 把 Claude 当生产力工具使用的商务专业人士（运营、营销、产品管理、教育、传播、知识工作）。**不是** API／程序开发路线。 
**学习包类型：** 仅含原创学习笔记 — 综合自 **公开** 的 Anthropic 产品文档、说明中心、公开 Claude Academy 课程，以及已发布的 CCAO-F 考试蓝图。本学习包 **与 Anthropic 没有从属关系，未获其背书，也未获其赞助**。

## 考试机制（取自已发布指南）

| 项目 | 细节 |
| --- | --- |
| 题数 | **60**（全部计分） |
| 时间 | **120** 分钟（平均约 2 分钟／题） |
| 题型 | 单选题＋多选题；每题注明要选几个选项（「约 1/4 为多选题」仅为轶闻，并非出自指南） |
| 及格分数 | 量表分数 **100–1000** 中的 **720** |
| 语言 | 英文 |
| 交付 | Pearson VUE — 在线监考或考场 |
| 费用 | 每次约 USD $99（报名时确认） |
| 有效期 | **12** 个月；免费准时续约评测；失效后须重考完整考试 |
| 重考 | 常被引用的等待期：14／30／90 天；滚动一年内有次数上限 |
| 成绩报告 | 及格／不及格＋量表分数；各领域答对百分比仅供参考 |

**诀窍：** 按 **配分比重**（见下）研读各领域文件，不要按文件编号。文件编号依循用户的 7 领域地图；官方蓝图编号略有不同，但涵盖同一组七个主题。

## 建议研读顺序（按考试配分比重）

1. **领域 03 — 评估与验证输出（21%）** — 从这里开始；判断类题目主导整张考卷。 
2. **领域 04 — 工作流程集成与解决方案设计（16%）** — 情境题、利益相关者、重新设计。 
3. **领域 06 — 治理、风险与负责任使用（15%）** — 政策、隐私、高风险使用。 
4. **领域 02 — 提示与任务执行（14%）** — 打磨、拆解、迭代。 
5. **领域 01 — 平台与模型基础（12%）** — 功能＋ Haiku／Sonnet／Opus（／Fable）。 
6. **领域 05 — 设置与知识管理（12%）** — Projects、指示、connectors。 
7. **领域 07 — 故障排除与优化（10%）** — 诊断薄弱输出／工作流程。

**实作（公开产品）：** 在 claude.ai／Claude Desktop 上练习 Projects、Artifacts、Skills、Connectors、Research（Research／检索增强生成（RAG）容量需付费方案）。研读时搭配公开 Academy：Claude 101＋ AI 流畅度（4D：委派（Delegation）、描述（Description）、明辨（Discernment）、尽责（Diligence））。
