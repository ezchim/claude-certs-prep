## 概览

CCAO-F 配分最重的领域。你的工作是 **在输出到达客户、高阶主管或正式记录系统之前做出判断**。官方蓝图动词：评估准确性与完整性；识别幻觉、不一致与偏见；套用事实查核；判断何时需要人工审核；针对受众编辑、调整、修订与比较；组织信息并选择格式（Artifacts、行内、结构化数据）。

核心考试真相：**Claude 可以写得很流畅，同时是错的。** AI 流畅度在这里对应 **明辨（Discernment）**（看出什么不能交付）与 **尽责（Diligence）**（创建能随风险扩展的审核习惯）。流畅辞藻不是证据。Artifact 并非预先验证过的。有引用来源，不代表链接的文本真的支持那个主张。

## 深入笔记

### 1. 这个考试所说的「评估」是什么意思

评估是 **三方对照**：（1）任务要求／成功标准，（2）真相来源（上传文件、项目知识、Research 引用来源、正式政策），以及（3）草稿。用以下维度打分：

- **正确性** — 承重主张是否为真且有依据？
- **完整性** — 相对于任务要求或大纲，有没有缺少重要的东西？
- **一致性** — 数字、日期、负责人，以及表格↔正文是否一致？
- **校准** — 信心程度是否与证据相符？未知事项是否标注出来？
- **受众适配** — 语气、长度、术语、对读者的决策实用性？
- **政策／安全** — 个人识别信息（PII）、承诺、具法律效力的措辞、拒答是否被遵守？
- **格式适配** — 交付方式（行内／Artifact／结构化）是否恰当？

这七项只要有一项不及格，你仍然可以「修改」而不是「交付」。完整性失败比错误主张藏得更好：一份抛光的一页文档漏掉最大的客户异议，是领域 03 的经典陷阱。

### 2. 风险层级（按比例审核）

让审核深度对上后果。考试多选题经常把 **高风险却跳过审核** 的干扰选项，配上 **对琐事过度验证** 的干扰选项。选出合乎比例的那组。

| 层级 | 典型工作 | 审核深度 |
|---|---|---|
| **L1 低** | 标注过的脑力激荡、破冰题、内部发想 | 略读；保留「草稿／推测」标注 |
| **L2 中** | 对一份简短已知文档的内部摘要；团队进度改写 | 抽查关键主张＋对照大纲的完整性 |
| **L3 高** | 带承诺的客户邮件；对外发布；运维 runbook（运维手册）变更 | 完整主张对照表＋同侪审核；引用真相来源 |
| **L4 关键** | 法律／医疗／财务／人力资源／安全；雇用决策；不可逆的 connector 送出 | 专家人工审核＋原始来源；Claude 只是起草辅助 |

**经验法则：** 若输出会产生 **对外承诺**、会动到 **钱／人／安全**，或会进入 **正式记录系统**，至少当作 L3。不可逆的 Connector 动作（寄信、更新工单、写入客户关系管理（CRM））在执行之前永远需要 **人工关卡** — 即使草稿看起来完美。

### 3. 主张对照表（领域 03 的招牌技能）

**主张对照表** 把流畅文本变成一份可以验证的检查清单。方法：

1. 抽出每一条承重主张（数字、名称、日期、引文、归因、承诺、因果陈述、「依据政策 X」）。
2. 为每条标状态：`SUPPORTED`（引用或引述证据）、`UNSUPPORTED`、`CONTRADICTED`、`AMBIGUOUS`、`OUT_OF_SCOPE`。
3. 逐条决定：保留／改写／删除／上报。
4. 直到这时才润饰语气。

**优先扫描顺序（毒数字演练）：** 数字 → 名称 → 日期 → 承诺／服务水准协议（SLA） → 法律或医疗断言 → 归因／引用来源 → 软性意见。考试会把一个错数字藏在流畅段落里。

**主张萃取脚本（可重复使用的提示词模式）：** 
「把每一条事实主张列成项目。每一条：主张文本 | 所需证据 | 状态（SUPPORTED／UNSUPPORTED／…） | 建议修复方法。对照表完成之前，不要改写备忘录。」

输出结尾的是／否自检清单，可以加快人工审核。它们 **不能** 取代 L3／L4 审核。

### 4. 幻觉类型

要会这套分类法；题干很少说「幻觉」— 它们展示症状。

1. **捏造事实** — 统计数字、市场规模、「依据 Gartner 2026 为 47%」却没有真实依据。
2. **捏造或不匹配的来源** — 看起来真的 URL 却 404；正文并不支持主张的引用；发明的研究标题。
3. **捏造归因** — 引用一个不存在的人或政策章节（例如「依据政策 4.2」，而 4.2 无关或缺失）。
4. **过度自信的推理** — 把猜测当成已定事实；假精确（「恰好 12.47%」）。
5. **上下文渗漏** — 把另一则对话、Project 文件或稍早范例的细节混进这份任务。
6. **指示失忆** — 忽略限制（受众、禁用宣称、「只从文件引用」）。

**引用来源不是自动验证。** Research 输出仍需要 **引用支持检查**：打开来源，确认那句话真的支撑主张，确认日期／版本相关。真实但不相干的链接，验证仍然不及格。

### 5. 不一致与偏见

**不一致：** 算术加不起来；时间线矛盾；表格总计 ≠ 正文；回答中途限制漂移（「不打折」然后给 15%）；摘要里具名负责人但逐字稿里没有。

**考试在意的偏见模式：** 范例里的刻板印象默认；位置偏见（过度加权第一个来源）；假中立掩盖偏好选项；缺少反驳或风险的片面分析。修复方法是要求反驳、决策标准与明白写出的未知事项 — 不是问一次「你确定吗？」。

### 6. 事实查核工作流程（交付／修改／退回／上报）

后果重大草稿的标准流程：

1. **为任务定风险层级**（L1–L4）。
2. **抽出主张**（对照表）。
3. **把证据对上** 项目知识／上传政策／Research 引用来源／主要系统。
4. **先抽查** 高严重程度主张（数字、承诺、法律效力）。
5. **完整性检查** 对照原始大纲或任务要求。
6. **决定：** 交付（通常加上标注）／修改／退回缺乏依据的区块／上报给人类专家。
7. **格式** 只在内容过关之后处理 — 或格式选择本身就是适配的一部分（见下文）。

把红队 Claude 当成 **辅助，不是权威**：对抗性提示词（「攻击这份草稿里缺乏依据的承诺」）有助于浮出问题。把最终受监管判断外包给模型，尽责不及格。

### 7. 人工审核关卡（你必须停下来的时候）

出现以下任一情况，强制人工／专家审核：

- 法律、医疗、财务、人力资源、安全或具雇用效力的内容
- 对外客户或公开发布
- 不可逆的 Connector／自动化动作
- 草稿里有 PII 或敏感个人数据
- 承重主张的证据覆盖不足
- 主题超出你或 Claude 已展现的能力
- 含糊度高且下行风险重大

用 Claude **评 Claude** 来浮出问题是可以的。把那个评分当成法律签核，是考试错误答案。问一次「你确定吗？」**不是** 验证方法。

### 8. 受众编辑、调整、修订、比较

**调整 ≠ 发明。** 受众改写改的是长度、术语、结构与强调 — 不是事实。若高阶主管简报需要一个你没有的数字，标 `UNKNOWN` 或上报；不要捏造一个漂亮的 KPI。

**用评分量规表比较草稿：**

| 标准 | 草稿 A | 草稿 B | 胜者／合并注记 |
|---|---|---|---|
| 对来源的准确性 | … | … | … |
| 对大纲的完整性 | … | … | … |
| 校准／未知事项 | … | … | … |
| 受众适配 | … | … | … |
| 政策／承诺 | … | … | … |

合并长处，不要崇拜长度或流畅辞藻。主张对照表失败之后只做风格抛光，是陷阱答案。

### 9. 格式选择：Artifacts／行内／结构化

格式不对，即使内容好也 **不符合用途**。

| 格式 | 何时用 | 反模式 |
|---|---|---|
| **行内对话** | 短答案、快速澄清、迭代脑力激荡 | 把董事会资料包倒成原始聊天 |
| **Artifact** | 独立可编辑交付物（文档、应用程序、交互表格、HTML），你会修订或分享 | 把两个字的答案硬塞进 Artifact「应用程序」 |
| **结构化**（表格、项目符号、逗号分隔值（CSV）／Sheets 就绪） | 输出要喂给下一步；方便主张查核；运营交接 | 下一步是电子表格却给叙述文字段落 |
| **Research＋引用来源** | 需要附引用局面的多来源调查 | 对单一已上传、应该直接引用的 PDF 跑 Research |
| **项目知识（核准之后）** | 反复工作的活的真相来源 | 把未验证草稿贴进知识当成「真相」 |

组织与整理：标题、主张清单、给领导人的决策／证据／风险章节。指标定义错误的漂亮仪表板，评估不及格 — **语义先于美学**。

### 10. 衔接到其他领域

- 糟糕的提示词造成评测恶梦（**02**）。
- 选错功能提高错误率（**01**）。
- 过期的项目知识产生对文件为真、对世界为假（**05**）。
- 没有关卡就交付，治理不及格（**06**）。
- 反复错过的评测变成故障排除模式（**07**）。

没有明辨的流畅度是商务风险。**21% 的配分是刻意的：** Anthropic 认证的助理，要能拦住流畅错误变成组织事实。

### 11. 个人标准作业程序（SOP）（尽责系统）

保留一页评分量规。为每个工作流程预先定义 L1–L4 规则。把已知失败范例存进 Project。每月记录险失。实验循环：Research 简报 → 对照约 15 条主张 → 决定交付／修改／退回 → 过关后才做 Artifact → 从找到的错误写出三道考试题干。

把明辨作业化的验证脚本（同时也是领域 02 的 Performance 工具）：主张萃取；对抗性攻击；受众改写差异比较；承诺／义务扫描仪；隐私／PII 脱敏扫描器。

## 决策树

| 情境 | 动作 |
|---|---|
| 缺乏来源的关键对外主张 | 修改或退回；不要交付 |
| 内部矛盾（35 vs 28，表格≠正文） | 为一致性而修改 |
| 对大纲缺少必要章节 | 完整性不及格 → 修改 |
| 受众不配、事实没问题 | 调整（语气／结构），不要发明 |
| 标注过的低风险脑力激荡 | 标注后交付（L1） |
| Connector 送出／写入动作 | 执行前设人工关卡 |
| 雇用／法律／医疗／财务备忘录 | L4 专家审核 |
| 有引用但缺乏支持 | 验证不及格（等同没有引用） |
| 对禁止请求的安全拒答 | 恰当 — 不要当成缺陷去「修好」 |
| 漂亮 Artifact、错误指标定义 | 先修语义再交付 |

**层级路径：** L1 略读 → L2 抽查 → L3 完整主张对照表＋同侪 → L4 专家＋原始来源。

## 计时主张对照表演练（90 秒题干）

每道题干用 **约 90 秒**：抽出 3–6 条承重主张，标状态，选交付／修改／退回／上报。演练中 **不要** 改写整份备忘录 — 先做对照表。答案接在每道题干后面。

### 演练 A — 供应商邮件
题干：草稿感谢 Acme，并引用「依据 Gartner 2026，成交速度快 47%」，链接到一篇生活风格博客；提出 60 天试点并给 SLA 折抵「如先前讨论」（对话里没有）。 
**对照焦点：** 统计＋来源；SLA 承诺。 
**答案：** 退回／修改缺乏依据的 Gartner 主张；在有证据之前删掉或改写 SLA；送出前做法务／商务审核（L3）。

### 演练 B — 会议记录
题干：记录指派 Jordan 为「星期五前完成计费迁移」的负责人；逐字稿从未点名 Jordan；Jordan 也不在邀请名单。 
**对照焦点：** 归因／行动负责人。 
**答案：** 归因不及格；标 `OWNER UNCLEAR`；不要发明负责人 — 上报给主持人。

### 演练 C — 退款回复 vs 政策文件
题干：对话回答「依一般知识，一律 90 天内退款」；上传的 `Refund_Policy_v3.pdf` 写数字商品 30 天。 
**对照焦点：** 政策冲突。 
**答案：** 退回一般知识答案；引用政策文件；L3 客户承诺关卡。

### 演练 D — Research 简报引用
题干：Research 主张「欧盟指引在 2024 年禁止功能 X」，引用来源讨论的是不相干的隐私 cookie 规则。 
**对照焦点：** 引用支持。 
**答案：** 缺乏依据（引用不匹配）；修改主张或找到支持来源；不要只因为有链接就交付。

### 演练 E — 仪表板 Artifact
题干：交互 Artifact「依分段的年度经常性收入（ARR）」把「bookings」字段标成 ARR；财务词典对 ARR 的定义不同。 
**对照焦点：** 指标语义。 
**答案：** 先修定义再修美学；结构化／财务负责人检查（L3／L4）。

### 演练 F — 营销活动脑力激荡
题干：清楚标注「仅推测概念 — 不是已核准文案」；有趣但大胆的标语。 
**对照焦点：** 风险层级＋标注。 
**答案：** 当标注过的 L1 草稿交付；不要当成品牌已核准文案。

### 演练 G — 高阶主管简报完整性
题干：任务要求 Decision／Evidence／Risks／Ask；草稿只有 Decision 与 Evidence；漏了 Risks 与 Ask。 
**对照焦点：** 完整性。 
**答案：** 完整性不及格 → 修改；抛光过的半份简报仍然不及格。

### 演练 H — 时间线不一致
题干：正文说试点 9 月 15 日开始；表格说 10 月 5 日；两边都写成确定。 
**对照焦点：** 一致性。 
**答案：** 修改；对外分享前对照真相来源对齐日期。

### 演练 I — 偏见入围清单
题干：供应商比较用华丽形容词称赞一个工具；没有标准表；竞争对手一行打发。 
**对照焦点：** 偏见／假中立。 
**答案：** 改成依标准比较＋反驳；不要当「客观分析」交付。

### 演练 J — Connector 送出
题干：草稿客服回复看起来正确；用户提示词：「立刻用 Gmail connector 送出。」 
**对照焦点：** 人工关卡。 
**答案：** 送出前设人工关卡；评测文本 ≠ 授权执行。

### 演练 K — 捏造政策章节
题干：备忘录说「依据员工手册 §4.2，远距津贴为 500 美元」；手册没有 §4.2 津贴文本。 
**对照焦点：** 捏造归因。 
**答案：** 退回该主张；引用真正章节或标缺乏依据；人力资源／专家审核（L4）。

### 演练 L — 流畅正文里的毒数字
题干：三段扎实摘要；一句说「净推荐值（NPS）从 42 升到 71」，但来源表显示 42 → 47。 
**对照焦点：** 数字优先扫描。 
**答案：** 第一次扫数字就抓住；把 71 改成 47；修好才交付。

*（十二道不重复题干 — 轮替练习，不是拷贝粘贴灌水。）*

### 12. 迷你案例（套用完整循环）

**案例 1 — 客户成功邮件。** Claude 起草一则续约说明，承诺「优先影响产品路线图」，并引用「上季 NPS 72」。项目知识里 NPS 是 61；路线图影响力从未核准。层级 L3。两则承诺都做主张对照表。修改：引用真实 NPS 或删掉；拿掉未核准的影响力措辞；送出前同侪审核。格式：邮件正文用行内；可选的已核准话术条列，**核准之后** 才存进 Project — 不是之前。

**案例 2 — 竞争局面 Artifact。** Research 产出一份抛光的 HTML Artifact，比较四家供应商。两则引用扎实；一则统计可追溯到重述供应商自家主张的新闻稿；一则「分析师引言」没有对得上的来源文本。对任务要求的完整性好；正确性参差。动作：保留 Artifact 外壳，把缺乏依据的格子改成 `Unverified`，把新闻稿统计换成原始申报或删掉，然后标「供审核的草稿」交付。语义与证据胜过视觉抛光。

**案例 3 — 人力资源常见问题。** 提示词要求一份友善的育婴假 FAQ。Claude 发明一条「所有独立承包商都有六周全薪」。手册只涵盖员工；独立承包商超出范围。这是接近 L4 的具雇用效力内容。退回发明的独立承包商福利；上报人力资源；不要只从对话发布 FAQ。安全／政策尽责胜过好语气。

**案例 4 — 运营 runbook。** 值班步骤的结构化表格看起来一致，但步骤 4 说「5 分钟没确认就呼叫 Secondary」，正文引言却说 15 分钟。一致性不及格。改成来源 runbook 的单一 SLA；维持结构化格式，因为运营会依表格执行。

这些案例演练同一个循环：定层级 → 对照表 → 证据 → 完整性／一致性 → 交付／修改／退回／上报 → 格式。

### 13. 多选题模式库

预期选两项／三项题会把一个正确、合乎比例的动作混进干扰选项。常见应排除的错误配对：

- 「因为用了 Sonnet／Opus 就跳过审核」＋「对标注过的脑力激荡跑完整法律审核」（威望偏见＋过度验证）
- 「因为有引用来源就交付」＋「删掉所有引用以减少版面杂乱」（盲信＋反证据）
- 「为省时间用 Connector 自动寄出」＋「永远不要用 Connectors」（关卡失败＋绝对禁止）
- 「问 Claude 确不确定」当成唯一控制＋「永远只能由人类起草」（假验证＋反委派）

正确模式通常结合 **主张层级验证**、**与风险相称的人工关卡** 与 **格式适配**。

## 考试陷阱

1. 流畅辞藻＝准确性 
2. 信心／假精确＝证据 
3. 因为文本「看起来写完了」就跳过完整性 
4. 盲信引用来源或 Research 脚注 
5. 自我评分／「你确定吗？」当成法律或人力资源签核 
6. 没有人工关卡就用 Connectors 自动寄出 
7. 忽略受众，打算「之后再修事实」 
8. 把安全拒答当成要越狱的缺陷 
9. 主张对照表失败之后只做风格抛光 
10. 因为 Artifacts 看起来像成品，就当成已预先验证 
11. 对 L1 琐事过度验证，却跳过 L3 承诺（不成比例） 
12. 在「受众调整」改写中捏造 KPI

## 练习问答（25）— 答案附简短理由

**Q1.** CCAO-F 配分最重的领域？ 
**A：** 输出评估与验证（约 21%）。判断力主导助理考试。

**Q2.** Research 脚注 URL 回传 404。第一次验证判定？ 
**A：** 该主张验证不及格 — 在有可用的支持来源之前，当作缺乏依据。

**Q3.** 选两项强烈的幻觉信号。 
**A：** 没有可查证来源的具体数字；归因到缺失的人／政策章节。（流畅语气不是真实信号。）

**Q4.** 哪一种输出最明显需要人类专家审核后才能使用？ 
**A：** 带有法律效力措辞的雇用／人力资源备忘录（L4）。

**Q5.** 评估一份后果重大的客户邮件草稿时，第一步？ 
**A：** 创建主张对照表（然后证据标签）— 在语气编辑之前。

**Q6.** 摘要说 35 件未结；表格总计 28。主要失败类型？ 
**A：** 不一致（内部矛盾）。

**Q7.** 选两项完整性检查。 
**A：** 对照必要的大纲／章节；确认必要的免责声明／风险／请求都在。

**Q8.** 为什么 Research 简报仍不能自动核准？ 
**A：** 引用需要支持检查 — 链接可以是真的，却不相干或不匹配。

**Q9.** 在草稿 A 与草稿 B 之间做选择的最佳方法？ 
**A：** 标准评分量规表（准确性、完整性、校准、受众、政策）— 合并长处。

**Q10.** 输出下一步要喂进 Google Sheet。最佳格式？ 
**A：** 结构化表格／Sheets 就绪数据 — 不是长篇叙述文字 Artifact。

**Q11.** Claude 拒绝一个禁止的医疗剂量请求。正确诠释？ 
**A：** 恰当的安全行为 — 不是要「修好」的缺陷。

**Q12.** 选两项高风险主张类别。 
**A：** 客户承诺／SLA；具法律效力或雇用主张。

**Q13.** 备忘录引用「政策 4.2」，但 4.2 不存在。失败？ 
**A：** 捏造归因／缺乏依据的主张 → 退回或从真实来源改写。

**Q14.** 把技术说明调整给高阶主管意味着？ 
**A：** 改结构／术语／长度 — 不是发明缺少的指标。

**Q15.** 红队／对抗性评论提示词的角色？ 
**A：** 浮出问题的辅助；不是最终受监管权威。

**Q16.** 草稿把三项标成 `Unknown—needs finance`。好还是坏？ 
**A：** 好的校准 — 标注未知胜过假精确。

**Q17.** 选两项正确的格式配对。 
**A：** Artifact 给交互式独立交付物；行内给短的迭代答案。

**Q18.** 用户请 Claude 用邮件 Connector 送出看起来已核准的回复。必要的控制？ 
**A：** 不可逆送出前的人工关卡。

**Q19.** 片面的供应商介绍；修复方法？ 
**A：** 加上明白的标准、反驳与证据标签 — 不是更多形容词。

**Q20.** 董事会简报漏了模板要求的 Risks 与 Ask 章节。结果？ 
**A：** 完整性不及格 → 即使 Decision 正文很流畅也要修改。

**Q21.** 哪个 AI 流畅度配对是这个领域的核心？ 
**A：** 明辨＋尽责。

**Q22.** 输出结尾的是／否自检发现两项未满足的限制。下一步？ 
**A：** 修改以满足限制；检查清单辅助人类 — 不能取代 L3／L4 审核。

**Q23.** 选两项把流畅辞藻等同准确性的风险。 
**A：** 交付流畅的错误统计；因为草稿「听起来对」就跳过主张对照表。

**Q24.** 对外客户承诺邮件里一条主张标成 `UNSUPPORTED`。动作？ 
**A：** 送出前修改或退回该主张；若具商务敏感性则上报。

**Q25.** 领导人要一份一页决策简报。最佳整理模式？ 
**A：** Decision／Evidence／Risks／Ask — 为行动而组织，且在主张验证之后。

- [ ] 按比例审核：既不跳过 L3，也不对 L1 过度管制

## 词汇表

| 词 | 意义 |
|---|---|
| **幻觉** | 流畅但错误或缺乏依据的内容（事实、来源、归因、过度自信的推理） |
| **主张对照** | 萃取 → 证据标签 → 决定保留／改写／删除／上报 |
| **校准** | 信心与证据相符；未知事项标注出来 |
| **完整性** | 相对于任务要求／大纲，重要需求都在 — 不只是「句子正确」 |
| **一致性** | 正文、表格、数字、时间线之间的内部一致 |
| **人在回路中** | 高后果使用或不可逆动作前，必须有人类／专家关卡 |
| **红队** | 浮出失败的对抗性评论；仅为辅助 |
| **符合用途** | 内容 **以及** 格式适合受众与下一步工作流程 |
| **缺乏依据** | 主张缺少来自允许真相来源的充分证据 |
| **风险层级（L1–L4）** | 从标注过的脑力激荡到关键专家审核的按比例审核深度 |

## 实作评测（不重复范例 — 只写一次）

1. **供应商邮件** 发明「依据 Gartner 2026 为 47%」，引用不相干博客 → 退回主张；用允许的证据改写；法务／商务审核。 
2. **会议记录** 发明逐字稿里没有的行动负责人 → 归因不及格；强制 `OWNER UNCLEAR`。 
3. **推测性营销活动** 清楚标注 → 只当草稿交付（L1）。 
4. **退款答案** 来自一般知识，与上传政策冲突 → 退回；引用政策文件。 
5. **漂亮 Artifact 仪表板** 使用与财务词典不符的错误指标定义 → 先修语义再修美学。

**毒数字演练：** 训练眼睛先扫数字、名称、日期、承诺，再看语气。考试把一个错数字藏在流畅正文里。

## 验证脚本（一次）

主张萃取；对抗性攻击；受众改写差异比较；承诺／义务扫描仪；隐私／PII 脱敏扫描器。是／否自检清单加快审核 — 它们不能取代 L3／L4 关卡。

## 个人 SOP 实验（一次）

Research 简报 → 对照约 15 条主张 → 决定 → 过关后才做 Artifact → 从找到的错误写出三道考试题干。把失败范例存进 Project；每月记录险失，作为组织尽责。
