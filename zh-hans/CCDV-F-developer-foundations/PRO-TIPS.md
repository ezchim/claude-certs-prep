# CCDV-F 应试秘诀 — 如何考好这场考试

*各学习章节的配套；于 2026-08-23 从官方考试指南 1.0 版与本学习包提炼。本文件是应试技巧，不是内容——内容在第 01–06 章。*

**这场考试真正奖励的是什么：** 在一个点名的限制之下，挑出*运算上正确*的 API 机制。几乎每一题题干都藏着一个具约束力的限制（延迟、成本、缓存稳定性、安全、可审计性）。先找到它，再读选项——正确答案服务的是那个限制；干扰选项服务的是情境的氛围。

---

## 驱动策略的数字

- **53 题／120 分钟 → 每题约 2.26 分钟。** 长情境题干代表真正的预算是约 90 秒阅读＋约 45 秒决定。在短的模型选择与优化（MSO）／定义题上存时间，花在集成情境题上。
- **量表分数 720 及格，答错不扣分** — 绝不要留空白。标记后往前走；把 53 题全部扫过第一轮，胜过把前 30 题做到完美。
- **领域配分比重就是分诊法则：** 集成 33.1%＋MSO 16.8%＋Agent 14.7% ≈ 考卷的 65%。一题摇摆的集成题，代价约是一题摇摆评测题的三倍。
- **多选题是全对才给分。** 每题会注明要选几个——就选刚好那么多个。选你能*辩护*的 N 个选项，不要选 N 个「听起来有关」的。

## 读题干协议

1. 先读最后一句（真正的问题）。
2. 扫描题干找**限制关键字**：「p95」、「overnight」、「cost per task」、「compliance」、「multi-tenant」、「cache hit rate」、「user is waiting」。
3. 删去每一个违反该限制的选项——通常四个里有两个在这里出局。
4. 在幸存者之间，偏好**能完整解决问题的最简单机制**。

## 若题干说 X → 就想到 Y（反射）

| 题干信号 | 反射 |
| --- | --- |
| 过夜／大批量／「早上之前」／对成本敏感 | **Batch API**（成本 50%、无流式、异步）——官方样例题 Q1 模式 |
| 用户正在等待／交互式／p95 | 流式、更快层级、更小上下文——绝不要 Batch |
| 「缓存命中率很低」 | 稳定前缀之前的易变内容；变更过的工具定义；思考设置切换。顺序：tools → system → messages |
| 延迟关键 **且** 需要前沿质量 **且** 预算允许 | **快速模式**（Opus 5／4.8、`speed:"fast"`、溢价、独立速率限制，不是 Batch／Bedrock／Vertex） |
| 工具／数据源要「跨团队／应用重复使用」 | **模型上下文协议（MCP）服务器**（样例题 Q3 模式）——不是拷贝粘贴的客户端代码 |
| 不受信任的内容（网页、文档、用户上传）遇上工具 | 注入隔离：分隔符号、最小权限原则的工具、把检索到的文本当数据（样例题 Q2 模式） |
| 「他们该用哪个模型」 | 能通过他们评测的最小模型；凭证据升级，绝不要默认升级 |
| 「完全相同的输出」／确定性 | 陷阱——采样参数在现行模型上已移除，而且本来也从不保证确定性；答案＝schema＋验证 |
| Claude Code 里的团队行为必须被*保证* | Settings／permissions／hooks（强制执行）——CLAUDE.md 只*建议* |
| 正式环境的版本意外 | 钉定模型 ID；不带日期的 ID 是钉定快照，不是自动升级 |

## 预期的干扰选项原型

- **更大的锤子：** 用「最大模型／更大上下文窗口」去解一个其实是结构性的问题（任务拆解、缓存、检索）。重量／大小永远修不了结构。
- **不可能的组合：** Batch＋流式；在 Batch 里面做缓存预热；在现行层级上调 temperature。看到就删——这些是可查证的事实，第 01／03 章都列了。
- **氛围答案：** 重述目标（「改善提示词让它更可靠」）却不点名机制。如果你说不出它用的是哪个 API 功能，它就不是答案。
- **过度工程的 agent：** 题目只需要带验证器的 3 步工作流程就能满足所述审计要求，选项却丢出一个自主 agent。

## 48 小时计划

1. 重读第 03 章的集成目录＋第 01 章的决策树（那 65% 的核心），再读第 06 章的框架／托管词汇卡。
2. 重做每一章的「考试陷阱」表，以及那两张「若 X 就想到 Y」表。
3. 一次计时 53 题／120 分钟仿真；按领域计分；只重读最弱领域的章节。
4. 最后再扫一次 README 的领域配分比重表——脑中带着分诊顺序，胜过你临时能背的任何事实。

## 考试当日（在线监考）

政府核发证件备妥、桌面清空、接受环场扫描、连接稳定、关掉外置屏幕。提早报到——Pearson VUE 让你最多提早 30 分钟开始。当标记的题目绕回来时，相信你第一次基于限制的判读，除非你发现自己读错了某个事实——凭氛围改答案会掉分。
