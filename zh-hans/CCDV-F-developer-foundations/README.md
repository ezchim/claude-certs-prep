## 考试机制（官方考试指南 1.0 版，2026 年 7 月）

数值来自官方考试指南 1.0 版（2026 年 7 月），并对照公开的 Pearson VUE Anthropic 计划页面交叉查核：

| 项目 | 官方数值 |
| --- | --- |
| 考试代码 | **CCDV-F** |
| 题数 | **53** 题 |
| 时间 | **120** 分钟 |
| 及格分数 | 量表分数 **100–1000** 中的 **720** |
| 题型 | 单选题＋多选题；每题会注明要选几个选项（「约 1/4 为多选题」这个比例属传闻，并非来自考试指南） |
| 交付 | Pearson VUE（考场或在线监考），英文 |
| 费用 | 每次 **USD $125** |
| 有效期 | **12 个月**，有免费的准时续约评估；重考等待 14／30／90 天，每滚动 12 个月最多 4 次 |
| 建议经验 | 1–5 年工程资历＋约 6 个月以上 Claude／LLM 实践；Python 及／或 TypeScript |

粗略配速：每题约 2.3 分钟。情境题的题干很长——先读**限制**（延迟、成本、安全、缓存稳定性），再看选项。

## 官方八大考试领域（配分比重来自考试指南 1.0 版）

| 领域 | 配分比重 | 学习强度 |
| --- | --- | --- |
| 应用与集成 | **33.1%** | 最高 — API、流式、缓存、批量对即时、schema、设置／版本钉定 |
| 模型选择与优化 | **16.8%** | 高 — 模型家族、effort、成本／延迟、上下文窗口 |
| Agent 与工作流程 | **14.7%** | 高 — agent 循环、Agent SDK 模式、编排 |
| 提示与上下文工程 | **11.0%** | 中高 — 系统提示词、上下文预算、压缩 |
| 工具与 MCP | **10.6%** | 中高 — 工具设计、MCP 服务器／客户端、connector |
| 安全与防护 | **8.1%** | 中 — 机密、个人识别信息（PII）、护栏、破坏性动作关卡 |
| Claude Code | **3.1%** | 重点 — CLAUDE.md、settings、权限、Code 里的 MCP |
| 评测／测试／调试 | **2.6%** | 重点 — 评测框架、回归测试集、调试循环 |

## 建议学习顺序（主要路径）

1. **先浏览本 README**＋领域配分比重（30 分钟）。
2. **时间不够就先读第 03 章** — 应用／集成占 **33.1%**；再回头读 01／02。
3. **第 01 章（模型选择与优化，简称 MSO）** — 锁定模型／effort／成本决策树（16.8%＋集成题里的成本／延迟题干）。
4. **第 02 章（提示／Agent／工具）** — Agent 14.7%＋提示 11%＋工具／MCP 概念那一半的 10.6%＋API 工具合约。
5. **第 04 章（生产工程／评测／安全）** — 安全 8.1%＋评测 2.6%＋生产集成模式。
6. **第 05 章（加速器）** — 打包与交接（以情境题形式支撑集成＋Agent＋评测）。
7. **第六章（框架／托管／SDLC）** — Strands／LangGraph／PydanticAI 词汇、自托管对托管 agent、SE／SDLC 卡片、WebSocket 对 SSE（收尾最优先缺口）。
8. **计时练习：** 53 题／120 分钟 — 按领域计分；重读较弱章节的「如果 X 就想到 Y」表。

**脱机阅读提示：** 每个文件都是纯 Markdown（ATX 标题、表格、围栏 `text` 树状图）。若喜欢电子阅读器格式，可用你惯用的 MD→EPUB 工具转换；维持一章一个文件。
