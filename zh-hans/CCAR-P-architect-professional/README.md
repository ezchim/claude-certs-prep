## 考试机制（官方考试指南 v1.0，2026 年 7 月）

| 项目 | 值 |
| --- | --- |
| 题数 | **63** 题 |
| 时间 | **120** 分钟（平均约 1.9 分钟／题） |
| 及格分数 | 量表分数 **720**（范围 **100–1,000**） |
| 题型 | 单选题＋多选题（「选两项／三项」）；多为长篇、多重限制的情境题 |
| 交付 | Pearson VUE（在线监考或考场） |
| 有效期 | **12** 个月；准时续约免费、免监考 |
| 费用 | 每次应考 **USD $175** |
| 重考 | 等待期 14／30／90 天；任何滚动 12 个月期间最多 4 次 |
| 前置条件 | 无强制要求；**强烈建议具备生产环境 Claude 架构经验**；CCAR-F 有帮助但非必须 |

**计分说明：** 量尺计分的意思是 720 **不是**固定的答对百分比。多选题通常需**全部**选对才给分——不要假设有部分给分。

## 建议研读路径（4–6 周）—— 主要来源模式

1. **第 1 周：** 档 01 —— 模型、提示工程、上下文、架构模式；做完第 J 部分情境题。 
2. **第 2 周：** 档 02 集成那一半 —— RAG、MCP、授权（authZ）、延迟、能力膨胀（配分最重）。 
3. **第 3 周：** 档 02 评测那一半＋档 03 安全／治理；跑失效模式表。 
4. **第 4 周：** 档 04 利益相关者／生命周期／变革／价值（标出仅限伙伴的 GTM 界线）＋档 05 赋能；混合情境题。 
5. **第 5–6 周：** 计时 63 题／120 分钟套题；弱点循环；从情境题库冷写架构决策记录（ADR）。

动手练习：一条 RAG 路径、一条工具／MCP 路径、一个评测框架、一个 HITL 闸门、一次 Claude Code 组织设置仿真执行（即使只当成文档审查）。

**主要学习诀窍：** 对每一个官方领域，你都要能大声讲解：(1) 决策树，(2) 一张取舍对照表，(3) 最重要的三种失效模式，(4) 会挡住正式发布（GA）的生产检查清单项目。
