# CCAR-P 应试秘诀 —— 如何考好这场考试

*档 01–05 的伴读；于 2026-08-23 自官方考试指南提炼整理
v1.0 与本包提炼。只讲应试技巧。*

**这场考试真正奖励的是什么：** 在多重限制之下有纪律地*删去选项*。专业级题干会一次叠上 3–5 个需求（延迟＋数据驻留＋审计＋成本＋某种组织怪癖）；任何选项只要违反哪怕一条点名的限制就出局，活下来的通常是清单上最不起眼的架构。本包的最左侧模式规则，就是用一句话讲这场考试：**优先选能满足需求的最简单模式；只有证据说左边那个失败时，才往右移。**

---

## 驱动策略的数字

- **63 题／120 分钟 → 每题约 1.9 分钟** —— 四场考试里最紧的配速，却碰上最长的题干。没得商量的技巧：先读问题那一句，再从题干把限制收成一份清单。若你已经过了 30 秒还在「吸收情境」，读法就错了。
- **分诊：** 集成 19%＋解决方案设计 17%＋评测 16%＝52%。但软性领域（治理 14＋利益相关者 14＋赋能 7＝35%）是便宜分数，共用一个模板 —— **机制＋指标＋负责人**。三个都点名的答案，赢过形容词比较漂亮的答案。
- **量表分数 720、猜题不扣分、多选题全对才给分**（而且这场考试很爱出「选两项」、旁边还有三个听起来都站得住脚的选项 —— 鉴别点几乎永远是被违反的限制，不是质量高低）。

## 限制排除演练（每一道长题干都要用）

1. 先读问题那一句。
2. 列出限制：服务水准协议（SLA）数字、落地／合规用词、量级、预算信号、「审计人员」、「受监管」、「多租户」、谁拥有什么。
3. 删去违反任何一条限制的选项。
4. 在幸存者里：最左侧模式、能通过评测的最小模型、最小权限原则、最少活动零件。

## 题干说 X → 想 Y

| 题干信号 | 反射 |
| --- | --- |
| 「审计人员需要每一步的证据」 | 带阶段日志＋验证器的工作流程 —— 不是自主 agent |
| 「步骤未知／开放式调查」 | agent＋工具允许清单＋预算＋写入动作要人在回路中（HITL） |
| agent 工具太多／什么都做 | 最小权限原则：先移除工具（官方样例题 Q1） |
| 缓存命中率低／稳定提示词上成本暴增 | 稳定前缀放前面、易变内容放后面；不要再重排工具定义（样例题 Q2） |
| 检索增强生成（RAG）答案在模型不错的情况下仍然错 | 先诊断检索再碰模型（样例题 Q3）；要引用来源，否则拒绝作答 |
| 在直连 API vs Bedrock vs Vertex vs Foundry 之间选择 | 用限制排除看数据驻留／采购／身份 —— 永远不要凭品牌感觉（档 02 D5） |
| 「我们怎么知道它够好？」 | 黄金标准集＋对抗性＋回归评测；先代码裁判再模型裁判；在看实验数据**之前**冻结门槛（档 02 M7） |
| agent 做退款／付款／写入 | 授权（authZ）放在工具服务器＋schema 验证放在代码＋上限由代码强制执行，不是模型判断 |
| 多 agent 提案 | 要有真正的角色／权限边界，否则只是流程表演 —— 一个工作流程可能就够了 |
| 「利益相关者想要完全自主」 | 现在给价值＋稍后解锁＋点名风险＋书面对齐；高影响动作仍然要 HITL |
| 交接／hypercare（上线后密集支持）／生命周期 | 具名的直接负责人（DRI）＋结束日期＋runbook（运维手册）＋架构决策记录（ADR）日志 —— 点名拥有者的答案才得分 |
| 生产环境里的模型升级 | 钉选 → 影子／重放 → 金丝雀发布＋紧急停止开关 → 切换；提示词和模型是同一个发布产物 |
| 商务价值支柱 | 指南的五个：效率、转型、**生产力**、成本、性能 SLA |

## 预期的干扰选项原型

- **令人印象深刻的架构：** 多 agent、最大的模型、每一个工具 —— 违反最简单能用就好的规则。复杂精巧是诱饵。
- **单限制答案：** 延迟完美，却默默违反数据驻留（或反过来）。这是*选两项题的杀手* —— 每一个幸存选项都要对每一条限制检查一遍。
- **把提示词当控制：** 治理「靠提示词文本就解决了」。提示词永远不是完整的控制故事 —— 要搭配 authZ、HITL、监控、证据。
- **信任模型：** 让 Claude 决定退款资格、租户归属，或必须由代码强制执行的门槛。
- **评测当事后补丁：** 靠示范感觉出货；在固定门槛之前偷看数据；用 20 则对话的 A/B 测试加冕赢家。

## 时效观察清单（考试那一周要重新查证）

本包刻意教决策逻辑而不是产品型号，所以很少会过期。还是值得花 10 分钟看：目前的模型层级＋自适应思考／effort（思考力度）（思考预算与采样参数已是旧式做法 —— 本包在这一点上已经改过）、平台可用性差异（Bedrock／Vertex／Foundry）、Claude Code 组织受管理设置的行为。

## 48 小时计划

1. 重读档 02 第 K–M 部分（集成＋评测深挖 —— 占考卷 35%）以及档 01 的第 J 部分情境题，把评分键盖起来。
2. 重做档 03–05 的陷阱＋审查路由矩阵（03 D4）—— 软性的 35% 可压成机制／指标／负责人＋具名 DRI 的答法。
3. 从情境题库冷写两份 ADR（模式、模型、被拒绝的替代方案）—— 考试的长题干其实是变装的 ADR。
4. 计时 63 题／120 分钟套题，用完整配速；把限制清单演练练到自动化，重点是演练不是内容。

## 考试当日（在线监考）

身份证件、清空桌面、环境扫描、连接稳定。配速要狠：约 1.9 分钟／题，意思是任何一题坐到 3 分钟以上，就选你最好的幸存选项并标记。软性领域的题目是你的缓冲时间 —— 把它存进时间银行。复查标记题时，再核对限制，不要核对偏好。63 题全部都要作答。
