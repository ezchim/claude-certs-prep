# CCAR-F 应试秘诀 — 如何考好这场考试

*搭配文件 03–05（含补充篇）、08、09；于 2026-08-23 从官方考试指南 v1.0 与本学习包蒸馏而成。纯应试技巧。*

**这场考试真正奖励什么：** 从生产环境证据诊断 agentic 系统的失败，并选择*相称*的修复方法。反复出现的轴线是 **确定性 vs 概率性**：提示词与 few-shot 降低失败率；闸门、hooks 与代码把失败率降到零。只要题干提到合规、顺序、金钱，或「绝对不可」，计分答案就落在确定性那一侧。

---

## 驱动策略的数字

- **60 题／120 分钟 → 每题 2 分钟**，但题目聚成 **4 个情境题，从 6 题题库抽出 — 而这 6 题全部印在考试指南里。** 这是四场考试中最大的合法优势：直接研读情境本身（客服解决 agent、以 Claude Code 产生代码、多 agent 研究系统、开发者生产力、以 Claude Code 做持续集成（CI）、结构化数据提取）。走进考场时，你已经认识大约四套要调试的系统。
- **领域 1 占 27%** — Agent SDK 编排文件（08）的份量超过其他任何两份文件加总。D3 + D4 各 20%。
- **720 量表分数，猜题不扣分，多选题全对才给分。**
- **不在考试范围清单是武器：** 云端供应商设置、流式实现、定价／速率限制、向量嵌入、提示词缓存内部机制、电脑操作、视觉全部排除。建立在这些之上的选项，依定义就是干扰选项 — 不加思索删去。

## 题干说 X → 想到 Y

| 题干信号 | 反射 |
| --- | --- |
| 循环停不下来／过早停止／解析「I'm done!」 | `stop_reason`（`tool_use` 继续，`end_turn` 停止）— 绝不是字符串匹配，也绝不是把迭代上限当主要修复方法 |
| 报告里子代理日志很干净但涵盖面很差 | **协调者任务拆解太窄** — 怪指派，不要怪工作者（样例题 Q7） |
| Agent「无法委派」 | 协调者的 `allowedTools` 少了 `"Task"` |
| 子代理「不知道」协调者学到的某件事 | 上下文隔离 — 发现必须**在 spawn prompt 里传递**；没有任何东西会隐含地流过去 |
| 合规／财务流程中有步骤被跳过 | **程序化前置条件／PreToolUse 式闸门**，绝不是「加强提示词」（样例题 Q1） |
| 格式不一的工具结果让 agent 混乱 | **PostToolUse hook** 在模型看到结果之前先规范化 |
| 「绝对不可执行超过 $N」 | 拦截工具调用 → 挡下并改为升级给人类 |
| 大型多文件审查深度不一致／矛盾 | 注意力稀释 → 逐文件各跑一遍 + 独立的集成遍次 — **不是**更大的上下文窗口（样例题 Q12） |
| 大量代码变更后恢复 | 告诉它哪些文件改了，或开新会话并注入摘要 — 过期的工具结果是毒药 |
| 从一次昂贵分析探索两种设计 | 每个方向一个 `fork_session`；原本会话不动 |
| 团队里每位开发者的 Claude Code 行为不同 | 项目层级设置（`.claude/commands/`、项目 CLAUDE.md、rules）对上某人的用户层级文件 — 版本控制是判断线索 |
| 惯例横跨散落的文件 | `.claude/rules/` 搭配 `paths:` glob — 胜过每个目录各自的 CLAUDE.md，也胜过从标头推断 |
| 升级给人类 | 结构化交接数据报（ID、根本原因、金额、尝试记录、建议）— 人类看不到逐字稿 |

## 术语纪律

考试指南（因此整个题库）写的是 **Task tool** — 即使现行 Claude Code 已改名为 Agent，作答仍用指南词汇。同样原则处处适用：这场考试按考试指南 v1.0 的术语计分；文件 08 标出与现行文档的差异，让你不会感到意外，但不要去「纠正」考试。

## 预期的干扰选项原型

- **用提示词补丁修确定性问题**（「在系统提示词里加上它必须永远……」）。只能降低、绝不消除 — 题干说必须／绝不／合规时就是错的。
- **更大的窗口** 用来修注意力稀释或涵盖面问题。
- **范围外诱饵：** Bedrock 身份与访问管理（IAM）、定价层级、向量嵌入存储 — 听起来合理，但被明确排除。
- **卸责：** 去修子代理，而根本原因是协调者的任务拆解或缺失的上下文交接。
- **逐字稿假设：** 答案假设人类或子代理看得到它从未被给予的对话记录。

## 时效查核清单（考试那一周重新核对）

SDK 选项的确切拼法（`agents`、`fork_session`／`forkSession`、hook 回调字段）见 code.claude.com/docs/en/agent-sdk — 文件 08 页脚有列。五分钟；概念不会变，拼法可能会变。

## 48 小时计划

1. 把 08 从头到尾重读，然后读 09（两章合计占考卷 42%）。
2. 重读两份补充篇（04 的领域 2 机制、05 的领域 3 机制）— 这些是密集事实段落；记忆新鲜度有帮助。
3. 逐一走过印出的 6 个情境，用上面的反射表预测失败模式 — 这是最接近提前看到考卷的事。
4. 把 12 题样例题冷着重做；每一题现在都应感觉像机械动作。
5. 06–07 整章跳过（不在考试范围），01–02 也跳过（背景）。

## 考试当日（在线监考）

身份证件、干净桌面、房间扫描、稳定连接。情境区块一打开，花 30 秒辨认它是 6 个已公布情境中的哪一个 — 你预先走过的失败模式图就能为其中每一题定价。确定性胜过概率性；协调者先于工作者；指南术语胜过现行文档。每题都要作答。
