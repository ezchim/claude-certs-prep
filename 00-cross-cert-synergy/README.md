# Cross-Cert Synergy Pack — study once, deploy four times

*Built for back-to-back exam runs — most useful when sitting two or more of
the four certifications within the same week.*

## What this pack is

The four exams test **ten shared doctrines at four different altitudes**, plus
a small set of genuinely shared facts. This pack centralizes those so you learn
them once, then maps exactly where the exams **diverge** so shared knowledge
never bleeds into the wrong answer sheet.

| File | Job |
| --- | --- |
| `01-shared-core.md` | The 10 doctrines + shared facts, each with a four-exam framing table — the ~third of total content you should only learn once |
| `02-divergence-map.md` | Anti-contamination: scope fences, terminology deltas, per-exam unique mass, and "same stem, different correct answer" cases |

## What this pack is NOT

- **Not a replacement** for the four packs — every exam has a large unique mass
 (CCAO product judgment, CCAR-F Agent SDK mechanics, CCDV Integration detail,
 CCAR-P soft domains ≈ 35%) that only its own pack covers.
- **Not merged content.** Where the exams disagree on scope or vocabulary, the
 divergence map wins — read it the morning of each exam.

## The honest overlap picture

- **Doctrine overlap: high** (the 10 principles in `01` recur in every guide's
 sample questions and objectives — this is where the synergy lives).
- **Fact overlap CCDV ↔ CCAR-P: high** (caching, batch, patterns, model
 selection — mostly the same technical facts at builder vs architect altitude).
- **Fact overlap CCAR-F ↔ CCDV: medium, with fences** (agents/tools/Claude
 Code shared conceptually, but CCAR-F excludes several CCDV core topics).
- **Fact overlap CCAO ↔ the technical three: low** (model tiers and the
 verification instinct transfer; almost nothing else does — don't study API
 mechanics for CCAO or Projects mechanics for CCDV).

## How to use it

1. Day 1: `01-shared-core.md` end to end — it's the spine everything hangs on.
2. Then: one focused pass per exam, in exam order, with late-week second passes.
3. Every exam morning: 20 minutes on that exam's column in
 `02-divergence-map.md` — fences and vocabulary, nothing else.
