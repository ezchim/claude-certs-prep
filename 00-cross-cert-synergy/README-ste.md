# Cross-Cert Synergy Pack — study once, use it for four exams — Simplified Technical English

> **Note:** This edition follows the ASD-STE100 writing rules: simple present tense, active voice, one word = one meaning, sentences of 20–25 words or less. Technical names (Claude, CCAO, CCAR-F, CCDV, CCAR-P, Agent SDK, caching, batch) are exceptions and stay as written.

*This pack helps you when you sit exams one after another. It is most useful when you sit two or more of the four certifications in the same week.*

## What this pack is

The four exams test **ten shared doctrines at four different altitudes**. They also test a small set of shared facts. This pack puts those doctrines and facts in one place. You learn them once. Then the pack maps the exact points where the exams **diverge**. Then you do not use shared knowledge on the wrong answer sheet.

| File | Job |
| --- | --- |
| `01-shared-core.md` | The 10 doctrines + shared facts. Each item has a four-exam framing table. This is about one third of total content. You learn this part only once. |
| `02-divergence-map.md` | Anti-contamination: scope fences, terminology deltas, unique mass per exam, and "same stem, different correct answer" cases |

## What this pack is NOT

- **Not a replacement** for the four packs. Every exam has a large unique mass that only its own pack covers. CCAO: product judgment. CCAR-F: Agent SDK mechanics. CCDV: Integration detail. CCAR-P: soft domains ≈ 35%.
- **Not merged content.** Where the exams disagree on scope or vocabulary, the divergence map is the authority. Read it on the morning of each exam.

## The honest overlap picture

- **Doctrine overlap: high** (the 10 principles in `01` show again in every guide's sample questions and objectives. This is the synergy.)
- **Fact overlap CCDV ↔ CCAR-P: high** (caching, batch, patterns, model selection. These are mostly the same technical facts at builder level vs architect level.)
- **Fact overlap CCAR-F ↔ CCDV: medium, with fences** (agents, tools, and Claude Code are shared as concepts. CCAR-F excludes several CCDV core topics.)
- **Fact overlap CCAO ↔ the technical three: low** (model tiers and the verification habit transfer. Almost nothing else transfers. Do not study API mechanics for CCAO. Do not study Projects mechanics for CCDV.)

## How to use it

1. Day 1: Read `01-shared-core.md` from start to end. This file is the core. All other study uses it.
2. Then: do one focused pass per exam, in exam order. Do second passes late in the week.
3. Every exam morning: spend 20 minutes on that exam's column in `02-divergence-map.md`. Read fences and vocabulary. Read nothing else.
